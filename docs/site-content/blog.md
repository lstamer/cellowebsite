## Post List

**Component:** `src/components/blog/PostList.tsx`  
Posts are fetched via `getAllPosts()` (GROQ: `*[_type == "post"] | order(publishedAt desc)`). In development with an empty Sanity dataset, 9 mock placeholder posts are rendered to keep the layout visible.

### Featured Post

The first post in the result set is displayed as a large featured card with:
- Category badge (mono uppercase, accent color)
- Title (large display font)
- Excerpt (truncated to 3 lines)
- Author: "Luke Stamer"
- Published date (formatted, e.g. "April 7, 2026")
- Link: "Read →" text (hover: accent color)
- Link to `/blog/[slug]`

### Regular Post Grid

Remaining posts (index 1 onward) appear in a responsive grid (1 col mobile → 2 col desktop). Each card shows:
- Optional thumbnail image with category badge overlay
- Title (display font, 2-line clamp)
- Excerpt (2-line clamp, if present)
- Published date
- "Read →" link

### Placeholder image copy

When a post has no `mainImage`, the placeholder area shows the italic serif text:  
> *"Stamer"*

## Error State

**Source:** `src/app/blog/error.tsx`  
**Component:** `src/components/blog/BlogErrorState`

Shown if the blog index fails to load:

- **Title:** "The journal needs a quick reset."
- **Description:** "Something interrupted the blog index while it was loading. You can retry the page or head back to the homepage without losing the rest of the site."
- **Primary action:** "Back to Home" → `/`
- **Secondary action:** "Retry" (calls `reset()`)

## Individual Post Pages (`/blog/[slug]`)

Each published Sanity post generates a page at `/blog/[slug]`. See the `docs/site-content/blog/` directory for per-post markdown files (generated by `npm run content:export`).

### Article page template copy (non-Sanity strings)

These strings appear on every blog post page regardless of Sanity content.

**Source:** `src/app/blog/[slug]/page.tsx`, `src/components/blog/ArticleHeader.tsx`

| Element | Copy |
|---|---|
| Back navigation link | "← Back to Journal" → `/blog` |
| Author byline | "Lukas Stamer" |
| Date format | e.g. "April 7, 2026" (US locale, long month) |
| Reading time | "[n] min read" (estimated at ~250 wpm) |
| Empty body fallback | *"No content available for this post."* |
| Image unavailable fallback | "Image unavailable" + image alt text (if present) |
| Related posts label | "Continue Reading" |
| Related posts heading | **"More from the Journal"** |
| Related post link label | "Read →" |

### Article page error state

**Source:** `src/app/blog/[slug]/error.tsx`

- **Title:** "This article could not be fully rendered."
- **Description:** "A piece of article content failed while the page was loading. You can retry this post, or return to the journal and keep browsing."
- **Primary action:** "Back to Journal" → `/blog`
- **Secondary action:** "Retry" (calls `reset()`)

### Metadata (dynamic, per post)

Generated by `generateMetadata()` in `src/app/blog/[slug]/page.tsx`:

- **Title:** `[post.title] — Stamer Cello`
- **Description:** `post.excerpt` or fallback: `Read "[post.title]" on the Stamer Cello journal.`
- **Open Graph type:** `article`
- **Open Graph image:** `post.mainImage` at 1200×630 (via Sanity image URL builder)
